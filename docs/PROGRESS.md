# 進捗表
毎日、その日の Day にチェックを入れ、日付とログへのリンクを書く。
週の終わりに眺めて、遅れていたら **予備日で取り戻すか、計画そのものを削る**。
計画を守るために品質を落とすのは本末転倒なので、削る方を優先する。

凡例: `[ ]` 未着手 / `[~]` 途中 / `[x]` 完了
