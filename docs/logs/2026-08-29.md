## 3. 詰まったこと / 学んだこと

- `Rect.Contains` と `Rect.Intersects` を「半開区間」（`[x, x+w)`）で統一する必要があった。
  境界の扱いを揃えないと、`Contains` で真になる点が `Intersects` の判定と矛盾するケースが出る。
- `Normalize` は完全一致比較ができない（浮動小数点演算の誤差のため）。テストは
  `math.Abs(got-want) < epsilon` で比較する必要がある。

## 5. 設計メモ

- `Vec2` / `Rect` の全メソッドが値レシーバで新しい値を返す設計にした。ポインタレシーバにすると
  `a.Add(b)` が `a` を書き換えるのか誤解しやすく、バグの温床になるため。
- `internal/geom` は `ebiten` に一切依存しない。これにより GPU の無い CI 環境でも
  `go test` がそのまま通り、当たり判定や座標変換のロジックを安心してテストできる。
